Chrome Built-in Gemini Nano Setup

Detecting Chrome Prompt API...

How to enable Gemini Nano in Chrome:

  1. Ensure you are using Chrome 128+ or Chrome Canary.
  2. Open chrome://flags/#optimization-guide-on-device-model and set it to "Enabled BypassPerfRequirement".
  3. Open chrome://flags/#prompt-api-for-gemini-nano and set it to "Enabled".
  4. Relaunch Chrome, then visit chrome://components and click "Check for update" under Optimization Guide On Device Model to trigger the one-time model download.

Offline Smart Clustering (Zero-AI / Enterprise Air-Gapped)

🛡️ Zero-AI Mode is Active. Tabs are grouped using pure local heuristics, URL subpath hierarchy, and TF-IDF title keyword co-occurrence.

Why use Offline Smart Mode?

  • Enterprise-Safe: Complies with strict corporate DLP policies. No data ever leaves your device.
  • Air-Gapped & Firewalled: Functions with zero internet access, zero Chrome flags, and zero external AI dependencies.
  • Zero Cost: Completely free forever without any API keys or subscriptions.
  • Automatic Fallback: Even when you choose Gemini Nano or Cloud APIs, Foldnex will automatically fall back to this engine if your network or policy blocks AI.
