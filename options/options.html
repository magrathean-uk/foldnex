Offline smart mode

Groups tabs on this device from their titles, words from their addresses and a small word table built into Foldnex. Nothing is sent.

How it works

  • If a cloud or Ollama request fails or answers late, Foldnex applies this mode’s grouping; that request has already been sent.
  • Private windows always use this mode, whatever engine is selected: nothing is sent from them.

Model memory

How long Ollama keeps the model loaded after a cleanup. Foldnex sends this to Ollama with each cleanup request; your Ollama server decides whether to honour it. The Ollama server on this device is the first hop: it can itself run cloud models.

Rules & memory

URL rules override grouping and their tabs are not sent to a model. Private windows always use Offline smart mode and do not read rules. An unchanged window’s result is reused for up to six hours.
